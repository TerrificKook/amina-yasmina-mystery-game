# README_FOR_DINAR.md

## Что это

Это набор файлов для постановки задачи Codex по игре «Дневник Амины и Ясмины».

## Как использовать

1. Создай или открой папку проекта в Codex.
2. Положи в корень проекта файлы:
   - `GAME_DESIGN.md`
   - `CODEX_TASK.md`
   - `AGENTS.md`
   - `CODEX_START_PROMPT.md`
3. В Codex открой чат по этой папке.
4. Скопируй текст из `CODEX_START_PROMPT.md` и отправь его в Codex.
5. После генерации попроси Codex проверить запуск:
   - `npm install`
   - `npm run dev`
   - `npm run build`

## Можно ли играть с телефона

Да, если Codex сделает адаптивную вёрстку по заданию.

Есть два сценария:

### 1. После публикации сайта
Самый удобный вариант. Загружаешь игру на Vercel, Netlify, GitHub Pages или другой хостинг. После этого открываешь ссылку с телефона как обычный сайт.

### 2. Локально с компьютера
Можно открыть с телефона, если телефон и компьютер в одной Wi-Fi сети.

Для Vite обычно нужно запускать так:

```bash
npm run dev -- --host 0.0.0.0
```

Потом на телефоне открыть адрес компьютера в локальной сети, например:

```text
http://192.168.1.25:5173
```

`localhost` на телефоне не сработает, потому что для телефона `localhost` - это сам телефон, а не твой компьютер. Да, интернет построен на таких маленьких издевательствах.

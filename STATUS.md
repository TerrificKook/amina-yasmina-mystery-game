## Обновление: мобильное управление и графика

Исправлена проблема, из-за которой в вертикальном режиме телефона нижние кнопки могли не помещаться в экран или перекрывать игровую область.

Что изменено:

- мобильное управление стало компактнее: крестовина слева, кнопки "Очки", "Рывок", "Действие" справа;
- добавлен нижний safe-area отступ, чтобы кнопки не прятались под панелью браузера;
- на очень низких экранах скрывается лишняя нижняя подсказка и прогресс зон, чтобы карта и кнопки не налезали друг на друга;
- карта получила более аккуратный pseudo-pixel-art вид: меньше овалов и текстовых плашек, больше тайловых дорожек, пиксельных деревьев, предметов, опасностей и помощников;
- героини стали визуально понятнее: добавлены пиксельные детали лица, очки, руки, одежда и ноги;
- подписи объектов больше не лежат поверх карты, но остались как подсказки для наведения и доступности.

Проверено:

- production-сборка через Vite API с тем же `base: /amina-yasmina-mystery-game/` прошла успешно;
- локальный production-путь отвечает `200`:

```text
http://127.0.0.1:4173/amina-yasmina-mystery-game/
```

- HTML подключает собранные файлы из `/amina-yasmina-mystery-game/assets/`;
- мобильная проверка 390x844: нижние кнопки полностью видны;
- мобильная проверка 360x700: нижние кнопки полностью видны, карта не перекрывается панелью управления.

Важно: в текущей песочнице Codex обычные команды `npm run build` и `npm run preview` упираются в системное ограничение доступа при чтении `vite.config.js`. Сам файл существует и читается, а эквивалентная production-сборка с теми же настройками проходит. На обычном локальном запуске и в GitHub Actions это ограничение не должно проявляться.

## Текущий результат

Исправлена проблема, когда GitHub Pages мог зависать на тексте:

```text
Игра загружается...
```

Код игры и геймплей в этой правке не менялись.

## Причина проблемы

Страница на GitHub Pages показывала fallback-текст, но React-приложение не запускалось. Причина: `index.html` был не приведён к обычному рабочему Vite/React-виду для production-публикации.

Для Vite важно, чтобы в корневом `index.html` были:

- `div id="root"`;
- подключение entrypoint:

```html
<script type="module" src="/src/main.jsx"></script>
```

Во время `npm run build` Vite заменяет этот путь на собранный файл из `/amina-yasmina-mystery-game/assets/...`.

## Что исправлено

- `index.html` приведён к стандартной структуре Vite/React.
- Внутри `div id="root"` оставлен только короткий fallback-текст `Игра загружается...`.
- React теперь должен заменять fallback после загрузки.
- `package.json` возвращён на обычные команды Vite:
  - `npm run dev` -> `vite --host 0.0.0.0`;
  - `npm run build` -> `vite build`;
  - `npm run preview` -> `vite preview --host 0.0.0.0`.
- Удалены кастомные обходные скрипты:
  - `scripts/vite-build.mjs`;
  - `scripts/vite-dev.mjs`;
  - `scripts/vite-preview.mjs`.
- `vite.config.js` проверен: `base` остаётся `/amina-yasmina-mystery-game/`.

# STATUS

## Короткий итог

Проект доведён до более цельного vertical slice: теперь в игре две полноценные ветки — **«Дневник Амины и Ясмины»** и **«Тайна Полины и Яблочного сада»**. Обе истории стали ближе к top-down action adventure / light roguelite: есть вступление, несколько зон, понятная цель, сбор предметов, препятствия, опасности, помощники, способности и финальная сцена.

## Причина белого экрана на GitHub Pages

Локальная production-сборка работает правильно: `vite.config.js` содержит `base: '/amina-yasmina-mystery-game/'`, а собранный `index.html` ссылается на файлы из `/amina-yasmina-mystery-game/assets/...`.

На живой Pages-ссылке сейчас отдавался исходный `index.html` со строкой:

```html
<script type="module" src="/src/main.jsx"></script>
```

Для GitHub Pages это неправильный вариант: браузер пытается загрузить исходный файл `/src/main.jsx`, а не собранный JavaScript из `dist`. Поэтому на телефоне и в браузерах появлялся пустой экран. Это похоже не на ошибку React-логики, а на публикацию исходников вместо готовой сборки.

Что важно после push: в GitHub Pages должен быть выбран источник **GitHub Actions**, чтобы публиковалась папка `dist`, которую собирает workflow.

## Что исправлено для production

- Проверен `vite.config.js`: base path правильный — `/amina-yasmina-mystery-game/`.
- Проверен `index.html`: есть `div id="root"`.
- Проверен `src/main.jsx`: React рендерит `App` в `root`.
- Добавлен аварийный экран `ErrorBoundary`: если в React случится runtime-ошибка, игрок увидит понятный экран ошибки вместо пустой страницы.
- В `index.html` добавлен простой стартовый fallback «Игра загружается...», чтобы при проблеме с загрузкой собранных файлов страница не выглядела полностью пустой.
- Проверены импорты на чувствительность к регистру: проблем не найдено.

## История Амины и Ясмины

Теперь это отдельная полноценная ветка **«Дневник Амины и Ясмины»**.

Зоны:

1. Квартира Динара: странный вечер и первая страница дневника.
2. Лесная тропа Тэфи: следы, кусты, мох, шорохи и вторая страница.
3. Странная лавка: жетоны, полки, тени и третья страница.
4. Озёрная поляна: финальный сбор озёрных огней и Светлячкового ключа.

Механики:

- Амина: способность **«Зоркий блогер»** подсвечивает скрытые подсказки и важные предметы.
- Яся: способность **«Игровой рывок»** помогает быстро проходить опасные участки.
- Тэфи помогает находить скрытые тропы.
- Скиппи даёт защиту или показывает секрет.
- Динар даёт короткие смешные подсказки, но не решает игру за игрока.

## История Полины

Ветка **«Тайна Полины и Яблочного сада»** сохранена и развита.

Зоны:

1. Стартовая поляна.
2. Яблоневый сад.
3. Лабиринт тропинок.
4. Финальная поляна Старой Яблони.

Механики:

- Цель: собрать 3 части яблоневого ключа — Лист, Яблоко и Звезду.
- **Очки Полины** подсвечивают скрытые символы и предметы.
- **Муха-рывок** даёт короткое ускорение.
- Котики-смотрители помогают лечением, защитой и подсказками.
- Кубики, ритм-шаги и милая муха-подсказка добавляют детали характера Полины без использования чужих ассетов.
- Финал проходит у Старой Яблони.

## Как проходить

Общий принцип одинаковый для обеих историй:

1. Выбрать историю и героя.
2. Прочитать короткое вступление.
3. Смотреть текущую цель в верхней панели.
4. Собирать нужные предметы в каждой зоне.
5. Использовать способность героя, если предмет скрыт или нужно быстро пройти опасность.
6. Подходить к помощникам и нажимать `E`, если нужна подсказка, лечение или защита.
7. Когда цель зоны выполнена, идти к выходу в следующую зону.
8. В финальной зоне собрать последние предметы и войти в светящееся место.

Ориентировочная длительность первого полного прохождения: около 10-15 минут, если читать вступления, изучать зоны и не бежать сразу по прямой.

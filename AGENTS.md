# AGENTS.md — Постоянные инструкции для Codex

Это проект «Дневник Амины и Ясмины» — маленькая красивая семейная игра. Соблюдай правила ниже во всех изменениях.

## Главное
- Лучше **короткая, красивая и законченная** игра, чем большая и недоделанная.
- Никогда не оставляй TODO, заглушки, пустые экраны и «временный» код. Всё, что добавлено, должно работать.
- Не используй официальные материалы Gravity Falls (имена, персонажи, места, шрифты, музыку, картинки, логотипы) и любые другие защищённые ассеты. Всё оригинальное: графика — SVG/CSS, шрифты — свободной лицензии.

## Код
- Пиши **аккуратно и просто**. Понятные имена переменных и компонентов.
- **Не усложняй архитектуру.** Никаких лишних библиотек, абстракций и паттернов. React + Vite + CSS достаточно.
- Один компонент = одна понятная задача. Тексты и данные держи в `src/data`, а не в коде компонентов.
- Комментируй неочевидные места **простыми словами на русском** — проект читает человек без опыта разработки.
- Состояние игры — в одном месте (`GameContext`). Не разноси логику хаотично.

## Язык и тон
- **Весь текст интерфейса и диалогов — на русском.**
- Тон тёплый, семейный, с лёгким странным юмором. Без хоррора и пугающих сцен.
- Амина — старшая, наблюдательная, рассудительная. Ясмина — младшая, живая, смелая, любопытная. Динар (папа) — помощник, иногда шутит и сам попадает в нелепые ситуации, но не решает загадки за детей.
- В финале обязательно есть тёплое личное послание с именами: Амина, Ясмина, Динар.

## Качество
- После изменений мысленно (и фактически) **проверяй запуск**: `npm run dev` работает, `npm run build` собирается без ошибок, в консоли браузера чисто.
- Проверяй адаптивность хотя бы логически: ширина 360–430 px, крупные кнопки, дневник и модальные окна не вылезают за экран.
- Проверяй, что игру можно пройти до конца без тупиков, все загадки решаемы, есть подсказки и мягкая реакция на ошибку.
- Звук всегда можно выключить; отсутствие звуковых файлов не должно ломать игру.

## Объяснения
- Когда вносишь заметное изменение, **кратко объясни простыми словами**, что и зачем сделал, чтобы папа без опыта разработки понял.
- Если что-то нельзя сделать без выбора (например, точное слово для шифра-загадки), выбери разумный вариант сам и отметь, где это легко поменять.

## Чего не делать
- Не подключать тяжёлые фреймворки и UI-киты.
- Не делать 3D.
- Не оставлять нерабочие кнопки и экраны.
- Не копировать чужой контент.

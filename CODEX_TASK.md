# CODEX_TASK.md — Задача для Codex

## Задача
Создай завершённую браузерную 2D-игру «Дневник Амины и Ясмины» на **React + Vite**.
Это короткое (10–15 минут) тёплое семейное мистическое приключение для двух девочек (Амина 12, Ясмина 10) и их папы (Динар). Полностью на русском языке. Должна быть **красивой и законченной уже в первой версии**, без TODO и заглушек.

Дизайн, сюжет, персонажи, загадки и стиль описаны в `GAME_DESIGN.md` — следуй ему. Постоянные правила работы — в `AGENTS.md`.

## Технологии
- React 18 + Vite.
- Адаптивная вёрстка для компьютера, планшета и телефона.
- Touch-friendly управление: все клики, загадки и drag&drop должны работать пальцем на мобильном экране.
- Чистый CSS (CSS-модули или один глобальный + покомпонентные стили). Без тяжёлых UI-библиотек.
- Анимации — CSS (transitions/keyframes) и небольшой JS для параллакса/частиц.
- Звук — Web Audio API (генерация простых тонов) + опционально CC0-файлы из `public/sounds`. Если файлов нет — звук не должен ломаться.
- **Без 3D, без чужих ассетов, без защищённых материалов.**

## Запрет на официальные материалы
Категорически запрещено использовать имена, персонажей, названия мест, шрифты, музыку, логотипы и изображения из сериала Gravity Falls или любого другого защищённого произведения. Всё — оригинальное. Графику рисуем SVG/CSS. Шрифты — только свободной лицензии (Google Fonts: например Caveat для дневника, Inter/Nunito для интерфейса).

## Структура компонентов (логика)
- `App.jsx` — оборачивает всё в `GameContext`, рендерит текущий экран по состоянию `screen`.
- `GameContext` хранит: `screen` (start | select | location | final), `sceneId` (1..5), `character` (amina | yasmina), `journalPages` (массив), `journalOpen`, `muted`. Действия: `next()`, `chooseCharacter()`, `addJournalPage()`, `solvePuzzle()`, `toggleMute()`, `restart()`.
- Данные сцен/загадок/персонажей лежат в `src/data` — НЕ хардкодить тексты по компонентам.
- Загадки получают конфиг из `puzzles.js` и вызывают `onSolved()`.
- Подсказки: каждая загадка имеет кнопку «Подсказка» (текст из конфига). Неверный ответ — мягкая реакция, без проигрыша.

## Требования к контенту
- 5 сцен и 5 загадок строго по `GAME_DESIGN.md`.
- Выбор персонажа влияет на тон реплик (Амина — рассудительная, Ясмина — смелая/любопытная) и на маленькую механику подсветки/тряски (минимально, но заметно).
- Папа Динар — помощник: подсказки и сцена 4 (распутывание).
- Финал содержит **персональное послание с именами Амина, Ясмина, Динар**.
- Все тексты на русском, грамотные, тёплые, лёгкий странный юмор, без хоррора.

## Требования к красоте (обязательно в v1)
- Тёплая ночная палитра (см. GAME_DESIGN.md), градиентные фоны, анимированные светлячки, параллакс при движении мыши.
- Эффект печати текста в диалогах, плавные fade-переходы между сценами, подсветка активных объектов при наведении.
- Дневник с бумажной текстурой (CSS) и рукописным шрифтом.
- Финальная сцена — заметная анимация зажигания огней.

## Требования к запуску
- `npm install` ставит всё без ошибок.
- `npm run dev` запускает игру локально (Vite, обычно http://localhost:5173).
- `npm run build` собирает прод-версию без ошибок и предупреждений-блокеров.
- Игра работает в Chrome/Firefox последних версий на десктопе.
- Игра должна быть пригодна для телефона в браузере: Chrome на Android и Safari/Chrome на iPhone, без мелких кнопок и без элементов, уходящих за экран.

## Команды

## Требования к проверке (сделай сам перед сдачей)
- Пройди игру от стартового экрана до финала: все 5 загадок решаются, дневник пополняется, финал показывает имена.

- Интерфейс остаётся usable на ширине 360–430 px: кнопки крупные, текст читаемый, дневник и загадки не ломают экран.
- Звук можно выключить; без звуковых файлов игра не падает.
- Нет TODO, заглушек, «lorem ipsum», пустых заглушечных экранов.
- Код проходит `npm run build` без ошибок.

2. Проходится за 10–15 минут целиком, без тупиков.
3. Все 5 загадок рабочие, с подсказками и мягкой реакцией на ошибку.
4. Красивый, атмосферный, анимированный интерфейс уже в v1.
5. Работает на компьютере и может проходиться с телефона через браузер.
6. Полностью русский текст; персональные обращения к Амине, Ясмине, Динару.
7. Никаких официальных материалов Gravity Falls. Вся графика — SVG/CSS, шрифты свободной лицензии.
8. Чистая, понятная структура файлов, без заглушек.

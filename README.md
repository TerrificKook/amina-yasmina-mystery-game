# Семейные истории: Амина, Ясмина и Полина

Семейная браузерная игра на русском языке. Сейчас проект разворачивается в сторону лёгкого 2D action adventure: игрок выбирает историю, выбирает героя, бегает по карте, собирает предметы, избегает опасностей и использует способности.

## Истории

- **Дневник Амины и Ясмины** — лес, дневник, светлячки, Тэфи, Скиппи и папа Динар.
- **Тайна Полины и Яблочного сада** — яблочный сад, котики-смотрители, кубики, огоньки и папа Михаил.

В проекте не используются официальные материалы Gravity Falls, Minecraft, Roblox, Telegram, Huawei или других брендов. Визуал сделан через CSS и простые элементы интерфейса.

## Управление

- Движение: `WASD` или стрелки.
- Способность: `Пробел`.
- Действие рядом с помощником: `E`.
- На телефоне появляются экранные кнопки движения, способности и действия.

## Запуск локально

```bash
npm install
npm run dev
```

Локальный адрес:

```text
http://localhost:5173/
```

## Проверка сборки

```bash
npm run build
```

Готовая сборка появляется в папке `dist`.

## GitHub Pages

Проект подготовлен для публикации через GitHub Pages из GitHub Actions.

Ожидаемая ссылка после деплоя:

```text
https://terrificcook.github.io/amina-yasmina-mystery-game/
```

Workflow лежит в `.github/workflows/deploy.yml` и запускается при push в ветку `main`.

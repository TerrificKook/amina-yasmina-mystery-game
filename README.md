# Семейные истории: Амина, Ясмина и Полина

Браузерная мини-игра на русском языке. Это top-down action adventure / light roguelite: игрок выбирает историю, ходит по нескольким зонам, собирает важные предметы, избегает опасностей, использует способности и доходит до финальной сцены.

## Истории

- **Дневник Амины и Ясмины** — приезд к папе Динару, странный дневник, квартира, лесная тропа, лавка и озёрная поляна.
- **Тайна Полины и Яблочного сада** — ночной яблоневый сад, котики-смотрители, кубики, ритм-шаги, огоньки и Старая Яблоня.

В проекте не используются официальные ассеты, логотипы, музыка, персонажи или защищённый визуальный стиль известных брендов. Графика сделана оригинально через CSS и простые элементы интерфейса.

## Управление

- Движение: `WASD` или стрелки.
- Основная способность: `Пробел`.
- Рывок: `Shift` или `F`, если у выбранного героя есть рывок.
- Действие рядом с помощником: `E`.
- На телефоне появляются экранные кнопки движения, способности, рывка и действия.

## Как играть

1. Откройте игру.
2. Нажмите «Начать приключение» или выберите другую историю.
3. Прочитайте короткое вступление.
4. Следите за текущей целью в верхней панели.
5. Собирайте ключевые предметы, обходите опасности и переходите в следующую зону.
6. В финальной зоне соберите последние огни или части ключа и дойдите до главного светящегося места.

## Запуск локально

```bash
npm install
npm run dev
```

Локальный адрес для разработки:

```text
http://localhost:5173/
```

## Проверка production-сборки

```bash
npm run build
npm run preview
```

Локальный production-адрес:

```text
http://localhost:4173/amina-yasmina-mystery-game/
```

## GitHub Pages

Правильная ссылка после деплоя:

```text
https://terrifickook.github.io/amina-yasmina-mystery-game/
```

Проект подготовлен для публикации через GitHub Actions. Workflow лежит в `.github/workflows/deploy.yml`, собирает проект командой `npm run build` и публикует папку `dist`.

В настройках GitHub Pages должен быть выбран источник **GitHub Actions**, чтобы публиковалась собранная игра, а не исходный `index.html`.
